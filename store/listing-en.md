# Qrive — QR Links for Google Drive

## Summary

Create QR codes locally for files and folders already shared in Google Drive.

## Detailed description

Qrive adds a small QR button beside files and folders that are already shared in Google Drive. Select the button to view a QR code for the existing sharing link, copy the link, or save the QR image as a PNG file.

QR codes are generated locally in your browser and are never sent to an external service. Qrive does not use OAuth, account connections, a separate backend, analytics, advertising, or a remote QR service. If it cannot verify a trusted Google Drive link, it shows an error instead of creating a potentially incorrect QR code.

Generating a QR code does not make a file or folder public. Anyone who scans it must still satisfy the item's existing Google Drive access policy before they can open it. Qrive provides English and Korean interfaces and supports keyboard navigation, closing with Escape or an outside click, and natural focus handling.

Qrive runs only on drive.google.com and requests no additional Chrome API permissions. It is an open-source project released under the MIT License and is independently developed without affiliation with, endorsement by, or sponsorship from Google. Google Drive is a trademark of Google LLC.
